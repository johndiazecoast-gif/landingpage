HTML Elements Showcase

This page intentionally uses many HTML tags for educational purposes:

  • Headings: <h1> to <h6>
  • Paragraphs: <p>, divisions: <div>
  • Tables with <table>, <tr>, <td>, <th>, <caption>
  • Forms and controls: text, email, number, radio, checkbox, date, color, submit, reset, select, textarea, button
  • Lists: <ul>, <ol>, <li>
  • Links: <a> and images: <img>
  • Text formatting: bold, italic, <code>, and more
